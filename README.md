# ГТМ с учётом климатических изменений ГТС ЗФ ПАО «ГМК «Норильский никель»

Геотехнический мониторинг гидротехнических сооружений Заполярного филиала
ПАО «ГМК «Норильский никель» с учётом климатических изменений.

**Открыть:** https://alikerimov65.github.io/gtm-gts-nornikel/

- Интерактивная карта, паспорта объектов ГТМ, графики температурных профилей по ГОСТ 25358-2020
- Статусы НОРМА / РИСК / КРИТИЧНО, метеоданные, сводные отчёты DOCX
- Доступ — по ролевым паролям (наблюдатель / оператор); данные зашифрованы (AES-GCM)
- Общий реестр замечаний — собственный проект Supabase (шаблон настройки: `supabase_setup.sql`)

Независимый проект. Не связан с репозиторием gis-norilsk-geotermika.
