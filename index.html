Превентивные пороги температур грунтов

Деформации сооружений ГТС (геодезические наблюдения)

Пороги — рабочие превентивные значения макета для режимного мониторинга ГТС. Неравномерность осадки вдоль гребня/по площади сооружения — индикатор поперечных трещин и локальной неустойчивости откосов дамб. Предельные значения показателей состояния сооружений (критерии безопасности К1/К2) задаются во вкладке «Контрольные критерии» карточки объекта по данным декларации безопасности ГТС (ФЗ-117, ст. 9; ГОСТ Р 59873-2021) и выводятся во вкладках «Деформации» и «Пьезометрия».
Приоритет декларационных порогов над общими: гребень/отстойный пруд ТОФ — пьезометры 0П-1…10П-1 и уровень пруда по ДБ 2023 (табл. 2.2); плотина 3-х озёр (Дудинка) — осадки 5/8 мм/год и температура мерзлотной завесы −1,2/−0,2 °C по ДБ (разд. 11.5); динамика осадок «затухание / ∆2⋛∆1» — для объектов, где критерий установлен декларацией (ТОФ, дамбы НМЗ/НОФ, Дудинка).

Загрузка данных мониторинга ГТС

Формы ведомостей — по ПБ 03-438-02 (форма 4 — термометрия, форма 5 — уровнемерная решётка, форма 7 — деформации); методика замеров — ГОСТ 25358-2020 и ГОСТ 24846-2019. Объект определяется автоматически по названию ГТС в имени файла или в шапке ведомости («Хвостохранилище ТОФ», «Лебяжье», «ГПХ НМЗ»…); файлы, не относящиеся к объектам реестра, отклоняются.
🌡 Термометрия — журналы и ведомости температур (xlsx) Цветные объектные ведомости и журналы температур: строка = скважина × дата, глубины по столбцам; выгрузки АСДК: глубины со знаком «минус». Раскладка распознаётся автоматически и запоминается; недостающая t наружного воздуха догружается из метеоархива на дату замера.
Метод расшифровки журналов ГТС (как файл превращается в ряды базы)
Термометрия. 1) В первых 40 строках ищется строка меток: «Шифр скважины»/«Литер»/«Номер скважины» (в т.ч. опечатка «скавжины») + «Дата замера»/«Дата/время». 2) Правее меток ищется строка глубин — неубывающая серия ≥5 значений 0…60 м; для выгрузок АСДК — убывающая серия отрицательных (0, −0,5, −1…), берётся по модулю. 3) Строки данных: шифр скважины наследуется сверху вниз (объединённые ячейки), записи вида «(ТС-1)» трактуются как псевдоним текущей скважины; строки без даты и без замеров с текстом в левых столбцах — наименования сооружений (дамбы, поля) — становятся префиксом имени ряда «Сооружение · Скважина». 4) Принимаются строки с датой не позднее текущей и ≥2 температурами в диапазоне −60…+60 °C; строки «скважина забита / нет доступа» отбрасываются автоматически. Повторные замеры на ту же дату сливаются.
Пьезометрия. Сводные ведомости формы 5 (ПБ 03-438-02): строка меток «Дата замера» + «Отметка уровня», строка имён пьезометров («1П-1», «П-5»…); данные ниже, «-» = нет замера; имённая серия «Уровень водоёма (отм.), м» — из столбца отметки уровня. Длинные форматы (ревизионные ведомости, выгрузки АСДК): строка = дата + шифр + показание; повторы дат сливаются (последняя запись).
Геодезия. Журнал формы 7: блоки «Циклы измерений»; осадка = абс. отметка верха марки минус первая отметка марки, мм; переносятся только циклы с заполненными датами. Форма 8 (плановые смещения X/Y) в схему базы не входит — при необходимости загружается как примечание.
Статусы. После загрузки ряды автоматически участвуют в расчёте статуса объекта (пороги — кнопка «⚙ Пороги и КК») и в графиках вкладок «Термометрия», «Пьезометрия», «Деформации».
Разовая ведомость по простому шаблону (одна строка = одна точка замера):
Объект ГТС · Площадка · Скважина (шифр) · Дата замера (ДД.ММ.ГГГГ) · Глубина скважины, м · Глубина точки, м · Температура, °C · Источник (журнал, файл)
Температура — со знаком «минус» для отрицательных значений; разделитель десятичных — точка или запятая.
⬇ Шаблон XLSX
🏔 Архивы завесных скважин ГТС системы трёх озёр — расширенный шаблон под архивные журналы прошлых лет (12 завесных скважин плотины на ручье Артинатка). Загрузка архивов включает прямой контроль критерия К2 декларации (−0,2 °C) через расчёт НГК по многолетним рядам: для вычисления глубины нулевых годичных колебаний нужны замеры ≥2 лет и ≥4 месяцев в году.
⬇ Шаблон архива завесных скв. (3 листа: Замеры · Скважины · Инструкция) Лист «Замеры» совместим с простым шаблоном выше — заполненный файл загружается той же кнопкой «Выбрать файл»; листы «Скважины» и «Инструкция» справочные, парсером не читаются.
🧠 Ведомость геотермики нестандартного шаблона (xlsx) — универсальный распознаватель структуры + запоминание шаблона за организацией
💧 Пьезометрия — уровнемерная решётка (xlsx) Сводные ведомости формы 5 (ПБ 03-438-02): «Дата замера» + «Отметка уровня» + имена пьезометров по столбцам; а также длинный формат «дата · шифр · показание». Загруженные ряды появляются во вкладке «Пьезометрия» карточки объекта.
📐 Деформации — журналы геодезических наблюдений (xlsx / csv / pdf) Журнал формы 7 (ПБ 03-438-02): циклы измерений, осадка = отметка минус первая отметка марки, мм; распознавание строк «дата · марка · отметка/осадка», автоперенос во вкладку «Деформации» карточки.
📄 Отчёты и заключения по ГТС (docx / pdf) — распознавание: объект, сооружения, параметры дамбы/отстойника, контрольно-измерительная аппаратура, дефекты, условия эксплуатации, ремонты → предпросмотр → перенос в разделы карточки
📥 Приёмка в центральную базу — общий реестр (Supabase · GTS_ZFNornik) Каждая загрузка автоматически уходит в общий реестр со статусом «ожидает приёмки». Приёмку выполняет ответственный исполнитель после входа в раздел предписаний (роль «надзор»); принятые данные включаются в основную базу при очередном обновлении публикации.
Загруженные замеры сохраняются в браузере (localStorage) и сразу участвуют в графиках и статусах. Для включения в центральную базу передайте файл ответственному исполнителю проекта ГТМ.
